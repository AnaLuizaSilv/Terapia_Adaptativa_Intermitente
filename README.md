# Terapia_Adaptativa_Intermitente
O presente repositório armazena os códigos utilizados para desenvolver o projeto "Estudo da resistência celular em tumores a partir de um modelo de competição de Lotka-Volterra.", que faz parte da disciplina de Equações Diferenciais ministrada pelo professor Dr. Vinicius F. Wasques, no segundo semestre de 2026.
